## Pendências e limites

O código comercial **362** é usado para **Chocolate Quente (R$ 13,00)** e **Moça Expresso (R$ 10,00)**. Ambos foram preservados com IDs internos distintos; nenhum novo código comercial foi inventado. A duplicidade foi confirmada visualmente na terceira página recebida; confirmar com o proprietário qual código comercial deve ser corrigido.

Adicionais são 15 produtos comuns na mesma categoria, com indicação lanches/sucos na descrição. Não há relações obrigatórias, sabores, tamanhos, ingredientes adicionais ou regras novas de preço.

A marca oficial foi recebida visualmente: bolo com suporte verde, trigos, nome Vila Rica e texto Padaria e Confeitaria Artesanal sobre fundo creme. Sua integração depende do arquivo original local, que não foi disponibilizado pelo ambiente junto às imagens da conversa. Não foi redesenhada ou inventada. A identificação textual permanece provisória. Favicon oficial e fotos individuais ainda aguardam arquivos adequados.

O seed não sobrescreve o localStorage existente: versão/chaves e parser foram preservados. Pedidos e catálogos anteriores continuam intactos. Para conhecer o novo seed, prefira um perfil de navegador novo, preservando os dados anteriores. O serviço existente `localServices.demo.resetDemoData()` restaura o catálogo/pedidos e limpa o carrinho público: é destrutivo para dados locais e só deve ser chamado deliberadamente, após guardar qualquer informação necessária. O rascunho do PDV usa chave própria; não o reutilize sem revisão após uma restauração.

## Restauração deliberada no ambiente local

Prefira abrir um perfil de navegador novo para experimentar o seed, sem afetar o catálogo anterior. Se optar por restaurar o mesmo navegador:

1. Guarde os dados locais que deseja preservar. A restauração é destrutiva: substitui produtos, categorias e pedidos e limpa o carrinho público.
2. Finalize ou descarte explicitamente qualquer atendimento não finalizado no PDV, que usa chave própria. A restauração do store principal não apaga esse rascunho.
3. No servidor de desenvolvimento (`bun run dev`), execute no console do navegador somente se estiver ciente do descarte:

```js
const { localServices } = await import("/src/services/local/index.ts");
await localServices.demo.resetDemoData();
```

4. Recarregue a página para visualizar o novo catálogo. Esse caminho de importação é exclusivo do desenvolvimento Vite e não é uma instrução para produção.

Não foram implementados reset automático, migração silenciosa ou novo botão destrutivo. O serviço de restauração já existia e não foi alterado nesta sprint.
